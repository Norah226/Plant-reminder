# Planto 🌱
<img width="2400" height="1500" alt="app-showcase_v4" src="https://github.com/user-attachments/assets/85307a56-f0dd-4e98-997c-cd3d3ec42d97" />


Planto is a reminder app that helps you remember to water your plants 😉

## Features

* 🪴 Adding plant reminders with details (room, light, and water)
* 📊 Tracking daily watering progress with a progress bar
* ✏️ Editing and deleting reminders when no longer needed
* 🔔 Getting notifications based on watering days
* 🎉 Celebrating with an "All Done" page when all plants are watered
